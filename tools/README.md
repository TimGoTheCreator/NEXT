# IC Generator (Deprecated)

> **WARNING:** If you actually use this, get some help. Use other generators, PLEASE!
> This Python IC builder is deprecated and scheduled for replacement by a dedicated high-performance generation tool.

This folder contains the legacy Python script `icbuilder.py` used to generate initial conditions for NEXT. It outputs plain `.txt` files that NEXT can load directly.

Supported ICs: Plummer, Hernquist, disk, composite galaxy, mergers, uniform sphere, binary, figure-eight, cross, random solar systems.
